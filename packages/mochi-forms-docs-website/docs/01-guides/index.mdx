`mochi-forms` is a library to manage forms in a way that looks and feels just like plain React. It provides a quick and customizable forms API for any phase of a project, including:

- Fully functional helper components for rapid prototyping and simple forms.
- Higher order components for connecting existing components to the `mochi-forms` API.
- Direct access to the hooks that make this all possible, supporting whatever custom components you can dream up.

## History

`mochi-forms` is built on the impressive [Formik](https://github.com/jaredpalmer/formik) library by [@jaredpalmer](https://twitter.com/jaredpalmer) and various other contributors. Formik provided a strong foundation for build forms in React, but after adopting React Context performance became an issue. `mochi-forms` fixes these performance issues and rewrites the library from the ground up to separate the core functionality from its integration with React, ultimately simplifying the development and maintenance experience.

### Compatibility

`mochi-forms` is compatible with [React v16.8+](https://reactjs.org/docs/hooks-intro.html) and works with ReactDOM.
