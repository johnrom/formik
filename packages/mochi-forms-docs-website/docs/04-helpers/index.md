# `mochi-forms`: Helpers

## What is a Helper?

Most `mochi-forms` helpers come with a helper component, a hook, and a higher-order component. For example, the Controller which handles `mochi-forms`' state management with React:

- `<FormController />`
- `useFormController()`
- `withFormController()`
